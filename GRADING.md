# Grading guide (for reviewers and grading agents)

This repository is Tablematch, a sponsorship marketplace prototype, plus an eval suite for its AI and
automated decisions. Everything below can be checked in about a minute, offline, with no API key.

## Setup

```bash
pip install -r requirements.txt pytest httpx
```

## Claims and how to verify them

| # | Claim | Command | Expected result |
|---|---|---|---|
| 1 | App and grader tests pass | `python -m pytest -q` | `34 passed` |
| 2 | The offline eval suites run deterministically and reproduce the committed baseline | `python evals/run_evals.py --out check` then compare `evals/results/check/summary.json` to `evals/baseline/summary.json` | Identical suite counts and metrics (latency fields aside). Exit code 1, because 2 must-have thresholds fail by design of the current code |
| 3 | The CI gate passes against the baseline | `python evals/run_evals.py --compare evals/baseline/summary.json --gate regression` | Exit code 0 |
| 4 | Model suites do not report invented scores | `python evals/run_evals.py --suite vision messages` | Both listed under "Not run" |
| 5 | Every result is traceable to a case | `evals/baseline/results.jsonl` | 135 offline rows with input, output, score, notes |
| 6 | Graders are tested | `tests/test_evals.py` | 5 tests on the graders |
| 7 | Datasets are versioned and split | `evals/datasets/VERSION`, `split` field | `1.0.0`; every 5th case `held_out` |

## Where to look

- Eval design and results: `evals/README.md`
- Datasets and gold labels: `evals/datasets/*.jsonl`, generated by `evals/build_datasets.py`
- Graders: `evals/graders.py`; thresholds: `evals/thresholds.json`
- LLM judge rubrics and calibration rules: `evals/judges/`, `evals/calibration/`
- CI: `.github/workflows/evals.yml`

## Known failures (honest baseline)

- `routing.unsafe_auto_verify = 2`: unclear proof is auto-verified (cases `route-009`, `route-011`).
- `privacy.pass_rate = 0.5`: sponsors receive GPS metadata when face blur is off (`privacy-002`).
- Vision and message suites have not been run: no API key, and message drafting is not built.

The prototype's evidence checks are simulated by design (see `app/evidence.py`); the evals test the real
scoring, routing, matching, photo-gate and file-handling code around them.
