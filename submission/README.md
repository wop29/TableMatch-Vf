# Tablematch: deliverables

Tablematch is a sponsorship marketplace for New York supper clubs and independent events. Brands buy
placements at small events, money is held in escrow, hosts upload proof, and the platform releases payment
once the proof is checked.

- **Live app:** https://tablematch-prototype.onrender.com (first load can take about a minute while the free server wakes)
